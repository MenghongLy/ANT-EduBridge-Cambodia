ពិពណ៌នា

វគ្គសិក្សា Web Development នេះរចនាឡើងដើម្បីបង្រៀនមូលដ្ឋាននៃការរចនា និង development គេហទំព័រ។ វគ្គសិក្សាគ្របដណ្តប់ពីការផ្តើម HTML, CSS និង JavaScript រហូតដល់ការប្រើប្រាស់ React និង Node.js។ វាល្អសម្រាប់អ្នកដែលចង់ចាប់ផ្តើមក្នុងមុខរបរការងារ Web Development ឬលើកកម្ពស់ជំនាញរបស់ខ្លួន។

វគ្គសិក្សាផ្តល់ឧទាហរណ៍ជាក់ស្តែង ការងារទាក់ទងគ្នា និងឱកាសក្នុងការសិក្សាលើគម្រោងពិតប្រាកដ។ អ្នកនឹងរៀនពីបច្ចេកទេស និងច្បាប់ល្អបំផុតក្នុងការរចនាគេហទំព័រ រួមទាំងការអនុវត្តក្នុងឧស្សាហ៍។

មាតិកាវគ្គសិក្សា

ម៉ូឌុល ១៖ មូលដ្ឋាន HTML និង CSS រៀនបង្កើតរចនាសម្ព័ន្ធ HTML ក្រាហ្វិក និងរចនាប័ទ្ម CSS
ម៉ូឌុល ២៖ JavaScript សម្រាប់ Web រៀនភាសា JavaScript ដើម្បីបង្កើតលក្ខណៈស្វាគមន៍អន្តរកម្ម
ម៉ូឌុល ៣៖ React Framework ស្វាគមន៍ React និងរៀនបង្កើតលក្ខណៈ dynamic ដំណើរការ
ម៉ូឌុល ៤៖ Backend Development រៀល Node.js និង Express ដើម្បីលើកដង្កើល backend API
ម៉ូឌុល ៥៖ ការលើកដង្កើលគម្រោង ធ្វើការលើកដង្កើលគម្រោង Web Development ពេញលេញ

លទ្ធផលសិក្សា

ជំនាញក្នុងការបង្កើត Websites គ្របដណ្តប់ HTML, CSS, JavaScript និង responsive design
React Framework Knowledge រៀនបង្កើតលក្ខណៈ dynamic ដោយប្រើ React components
Backend Development Skills រៀន Node.js និង Express ដើម្បីលើកដង្កើល REST API
ការលើកដង្កើលគម្រោងពេញលេញ សមត្ថភាពក្នុងការលើកដង្កើលគម្រោង Web ពេញលេញ ពីដើមដល់ចប់
