# 🌍 EduBridge-Cambodia

A modern student opportunity platform designed to help users discover scholarships, internships, exchange programs, volunteer activities, and free learning resources in one place.

This project is built as a multi-page web application focused on accessibility, clean UI/UX, and easy navigation for students and young learners.

---

# 📌 Project Overview

The platform helps students:

- Find local and international scholarships
- Explore free online courses
- Discover exchange programs
- Apply for internships
- Join volunteer activities
- Improve career preparation skills
- Manage personal profiles and saved opportunities

The website supports both guest users and logged-in users with different homepage experiences.
